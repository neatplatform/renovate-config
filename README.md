# renovate

## Quick Start

For general-purpose repositories:

```json
{
  "extends": [
    "github>neatplatform/renovate"
  ]
}
```

For *Go* repositories:

```json
{
  "extends": [
    "github>neatplatform/renovate:go"
  ]
}
```

For *JavaScript* repositories:

```json
{
  "extends": [
    "github>neatplatform/renovate:javascript"
  ]
}
```
